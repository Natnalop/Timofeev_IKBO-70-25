## Задача 1

Вывести список имён пользователей из `/etc/passwd`, отсортированный по алфавиту.

```bash
cut -d: -f1 /etc/passwd | sort
```

- `cut` — как ножницы: режет строку по указанному символу и достаёт нужный кусок.
  - `-d:` — «режь по двоеточию»;
  - `-f1` — «оставь только первый кусок».
- `sort` — сортирует список по алфавиту (от a до z).
- `cat` — стандартная утилита Linux (сокращение от _concatenate_ — «объединять»). Читает файлы и выводит их содержимое в терминал, а также объединяет несколько файлов в один поток данных.

## Задача 2

```bash
grep -Ev '^#|^$' /etc/protocols | awk '{print $2, $1}' | sort -rn | head -5
```

- `grep -Ev '^#|^$'` — дословно: **«покажи все строки файла `/etc/protocols`, КРОМЕ тех, что являются комментарием или пустой строкой»**.
- `awk` — программа, которая построчно читает файл и автоматически разбивает каждую строку на поля по пробелам. Поля называются `$1`, `$2`, `$3` и т.д. (`$0` — вся строка целиком). Здесь `{print $2, $1}` меняет первые два поля местами.
- `sort -rn` — обратная числовая сортировка.
- `head -5` — оставить первые 5 строк.

## Задача 4

### Шаг 1. Поиск слов через `grep`

```bash
grep -oE '[A-Za-z_][A-Za-z0-9_]*' hello.c
```

- `-o` — вывести **только совпадения**, а не всю строку;
- `-E` — расширенные регулярные выражения (чтобы не экранировать спецсимволы).

### Шаг 2. Убрать повторения и отсортировать

```bash
sort -u
```

- `sort` — сортирует строки по алфавиту;
- `-u` (unique) — убирает дублирующиеся строки **после** сортировки.

### Шаг 3. Собрать всё в одну строку через пробел

По примеру ожидается вывод **в одну строку**, разделённый пробелами, а не по одному слову на строку. Для этого используем `tr`:

```bash
tr '\n' ' '
```

Заменяет символы перевода строки на пробелы.

### Итоговая команда

```bash
grep -oE '[A-Za-z_][A-Za-z0-9_]*' hello.c | sort -u | tr '\n' ' '
```

## Задача 5

```bash
#!/usr/bin/env bash

if [ "$#" -ne 1 ]; then
    echo "Использование: $0 <файл>" >&2
    exit 1
fi

src=$1
dest_dir=/usr/local/bin

if [ ! -f "$src" ]; then
    echo "Ошибка: файл '$src' не найден" >&2
    exit 1
fi

chmod 755 "$src"
cp "$src" "$dest_dir/$(basename "$src")"
echo "Команда $(basename "$src") зарегистрирована в $dest_dir"
```

### Как это работает

- `"$#" -ne 1` проверяет, что передан ровно один аргумент.
- `-f "$src"` проверяет, что файл существует и является обычным файлом.
- `chmod 755` даёт владельцу права чтения, записи и исполнения (`rwx`), а остальным — чтения и исполнения (`r-x`). Это стандартные права для команд.
- `cp` копирует файл в `/usr/local/bin`. `basename` убирает путь, чтобы `./reg ~/scripts/banner` тоже копировал файл под именем `banner`.
- Все переменные взяты в кавычки, иначе ShellCheck выдаст предупреждения (и скрипт сломается на именах с пробелами).

### Запуск

```bash
chmod +x reg
sudo ./reg banner
banner "Hello from RTU MIREA!"   # теперь работает из любого каталога
```

## Задача 6

```bash
#!/usr/bin/env bash

dir=${1:-.}

if [ ! -d "$dir" ]; then
    echo "Ошибка: '$dir' не каталог" >&2
    exit 1
fi

while IFS= read -r -d '' file; do
    first=$(head -n 1 "$file")
    case "${file##*.}" in
        c|js) pattern='^[[:space:]]*(//|/\*)' ;;
        py)   pattern='^[[:space:]]*#' ;;
    esac
    if [[ $first =~ $pattern ]]; then
        echo "есть комментарий: $file"
    else
        echo "нет комментария:  $file"
    fi
done < <(find "$dir" -type f \( -name '*.c' -o -name '*.js' -o -name '*.py' \) -print0)
```

### Как это работает

- `dir=${1:-.}` — каталог берётся из первого аргумента, а если его нет, то используется текущий.
- `find ... -print0` находит все файлы с нужными расширениями (включая подкаталоги). Имена разделяются нулевым байтом, поэтому пробелы в именах не ломают скрипт.
- `read -r -d ''` читает эти имена по одному.
- `head -n 1` берёт первую строку файла.
- `${file##*.}` отрезает всё до последней точки, то есть возвращает расширение.
- Для `c` и `js` комментарий начинается с `//` или `/*`, для `py` — с `#`. Перед ними допускаются пробелы.
- `[[ $first =~ $pattern ]]` проверяет строку регулярным выражением. `$pattern` здесь нужно писать без кавычек, иначе это будет обычное сравнение строк.

### Запуск

```bash
chmod +x check_comment
./check_comment ~/project
```

## Задача 7

```bash
#!/usr/bin/env bash

dir=${1:-.}

if [ ! -d "$dir" ]; then
    echo "Ошибка: '$dir' не каталог" >&2
    exit 1
fi

find "$dir" -type f -size +0 -exec sha256sum {} + \
    | sort \
    | uniq -w64 --all-repeated=separate \
    | cut -c67-
```

### Как это работает

- `dir=${1:-.}` — каталог берётся из аргумента, по умолчанию текущий.
- `find "$dir" -type f -size +0` находит все непустые обычные файлы, включая подкаталоги.
- `-exec sha256sum {} +` считает хеш содержимого каждого файла. Одинаковое содержимое даёт одинаковый хеш, независимо от имени файла.
- `sort` ставит строки с одинаковыми хешами рядом (хеш стоит в начале строки).
- `uniq -w64 --all-repeated=separate` сравнивает только первые 64 символа (сам хеш) и выводит только повторяющиеся строки, разделяя группы пустой строкой.
- `cut -c67-` убирает хеш (64 символа) и два пробела после него, остаются только пути.

### Запуск

```bash
chmod +x finddup
./finddup ~/project
```

## Задача 8

```bash
#!/usr/bin/env bash

if [ "$#" -lt 1 ] || [ "$#" -gt 2 ]; then
    echo "Использование: $0 <расширение> [каталог]" >&2
    exit 1
fi

ext=${1#.}
dir=${2:-.}

if [ ! -d "$dir" ]; then
    echo "Ошибка: '$dir' не каталог" >&2
    exit 1
fi

archive="archive_$ext.tar"

find "$dir" -maxdepth 1 -type f -name "*.$ext" -print0 \
    | tar --null -cvf "$archive" -T -

echo "Создан архив: $archive"
```

### Как это работает

- `ext=${1#.}` берёт расширение из первого аргумента и убирает точку в начале, если её ввели (`.c` и `c` работают одинаково).
- `dir=${2:-.}` — каталог необязателен, по умолчанию текущий.
- `find -maxdepth 1 -type f -name "*.$ext"` ищет файлы с нужным расширением только в самом каталоге, без подкаталогов (в условии сказано «в данном каталоге»). Чтобы искать и в подкаталогах, уберите `-maxdepth 1`.
- `-print0` и `tar --null` передают имена через нулевой байт, поэтому пробелы в именах не ломают скрипт.
- `tar -cvf "$archive" -T -` создаёт архив (`c`), выводит список файлов (`v`), имя архива задаётся через `f`, а список файлов читается со стандартного ввода (`-T -`).

## Задача 9

```bash
#!/usr/bin/env bash

if [ "$#" -ne 2 ]; then
    echo "Использование: $0 <входной_файл> <выходной_файл>" >&2
    exit 1
fi

in=$1
out=$2

if [ ! -f "$in" ]; then
    echo "Ошибка: файл '$in' не найден" >&2
    exit 1
fi

if [ "$in" -ef "$out" ]; then
    echo "Ошибка: входной и выходной файлы должны быть разными" >&2
    exit 1
fi

sed 's/    /\t/g' "$in" > "$out"
```

### Как это работает

- Два аргумента: входной и выходной файл.
- `-f "$in"` проверяет, что входной файл существует.
- `-ef` проверяет, что это не один и тот же файл. Иначе `> "$out"` обнулил бы файл раньше, чем `sed` его прочитает, и данные бы пропали.
- `sed 's/    /\t/g'` заменяет каждую последовательность из 4 пробелов на символ табуляции (`\t`). Флаг `g` заменяет все вхождения в строке, а не только первое. В шаблоне между слешами ровно 4 пробела.
- `> "$out"` записывает результат в выходной файл.

Символ `\t` в замене понимает GNU sed, а он есть в Linux (у вас Ubuntu).

## Задача 10

```bash
#!/usr/bin/env bash

if [ "$#" -ne 1 ]; then
    echo "Использование: $0 <каталог>" >&2
    exit 1
fi

dir=$1

if [ ! -d "$dir" ]; then
    echo "Ошибка: '$dir' не каталог" >&2
    exit 1
fi

find "$dir" -maxdepth 1 -type f -empty -name '*.txt'
```

### Как это работает

- Каталог передаётся параметром, как требует условие.
- `-type f` выбирает только обычные файлы.
- `-empty` выбирает файлы нулевого размера.
- `-name '*.txt'` оставляет только текстовые файлы. Кавычки нужны, чтобы шаблон раскрывал `find`, а не оболочка.
- `-maxdepth 1` ищет только в самом каталоге. Чтобы искать и в подкаталогах, уберите этот параметр.
