## Запуск работы 2

Требуется Python 3.11 или новее. Для анализа зависимостей используются
только модули стандартной библиотеки Python.

```powershell
.\run.bat
.\run.bat --stage 4 --reverse
python -m unittest discover -s tests -v
```

Linux и macOS: `sh run.sh`. По умолчанию запускается этап 5 с локальным
тестовым репозиторием. Параметры анализа читаются из TOML.

`src/main.py` выбирает самостоятельный этап из `Workbook2`.
В этапах 4 и 5 код расположен в `src`, проверки — в `tests`.
Прежние команды `python Workbook2/stageN/depgraph.py` сохранены.

Для визуализации нужен D2; готовые SVG доступны без установки D2.
PDF-отчет создается локально в `Workbook2/README.pdf` и не отслеживается
Git. Исходная документация хранится в Markdown. История содержит два старых
коммита с нестандартными названиями; история не переписана.
