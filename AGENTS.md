# Правила работы с репозиторием

- Перед каждым новым коммитом показать пользователю готовые локальные изменения и результаты проверок, спросить подтверждение и дождаться ответа.
- Не выполнять `git commit` и `git push` без явного подтверждения пользователя для соответствующего набора изменений. Предыдущие разрешения не считать разрешением на новый коммит.
- Не переписывать существующую историю коммитов без отдельного разрешения пользователя.
