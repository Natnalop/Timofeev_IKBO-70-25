# Этап 5

Самостоятельный снимок приложения, Python 3.11+, внешние зависимости отсутствуют.

```powershell
cd Workbook2/stage5
python depgraph.py --config config.toml
```

Описание параметров и алгоритмов находится в [общем README](../README.md).
Примеры глубины, фильтра, цикла и изолированной вершины: `examples/*.toml`.
Фактический вывод демонстраций сохранен в `examples/demo.txt`.

На этом этапе Python формирует и выводит текст D2, а программа D2 преобразует
его в SVG с раскладкой ELK. Из корня репозитория все три картинки создаются так:

```powershell
python Workbook2/stage5/examples/generate_real.py
```

Требуется D2 в PATH или `Workbook2/.tools/d2.exe`. Готовые SVG из `examples`
можно показывать без D2. Оформление: белый фон, черные подписи и рамки,
соединения из прямых отрезков.
