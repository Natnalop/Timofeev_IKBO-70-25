# Этап 5

Самостоятельный снимок приложения, Python 3.11+. Для анализа зависимостей внешние библиотеки не
требуются.

## Запуск

```powershell
cd Workbook2/stage5
python depgraph.py --config config.toml
```

Описание параметров и алгоритмов находится в [общем README](../README.md). Примеры глубины, фильтра,
цикла и изолированной вершины: `examples/*.toml`. Фактический вывод демонстраций сохранен в
`examples/demo.txt`.

## Создание изображений

На этом этапе Python формирует и выводит текст D2, а программа D2 преобразует его в SVG с раскладкой
ELK. Из папки `Workbook2/stage5` три картинки создаются так:

```powershell
python examples/generate_real.py
```

Требуется D2 в PATH или `Workbook2/.tools/d2.exe`. Готовые SVG из `examples` можно показывать без
D2. Оформление: белый фон, черные подписи и рамки, соединения из прямых отрезков.

## Исходники и проверки

Исходники находятся в `src/apkgraph5`, а собственные проверки CLI — в `tests`. Функция `to_d2()`
теперь находится в `src/apkgraph5/diagrams.py`. Проверки этапа: `python -m unittest discover -s
tests -v`. Сохраненный индекс — текстовый файл `examples/APKINDEX.txt`, архив в Git не требуется.
Для запуска этапа можно использовать `run.bat`.
